# Public ScreenRing phone download repository

- Public distribution documentation only. Keep the development repository private.
- Never copy TV artifacts, project source, Git history, device tools/data,
  keystores, signing properties, credentials or pairing keys here.
- Signed phone APKs, SHA256SUMS and public signer fingerprints belong in GitHub
  Release attachments, not in Git history. Never upload debug or unsigned APKs.
- Verify the package is de.agundur.screenring.phone and the release signature
  before uploading. Review the exact file list; never recursively upload dist/.
- Final support/privacy details and production signing must be complete before
  publishing a download. Do not invent these details.
- Public presentation includes the reviewed social artwork and the already-public
  KFritz screenshot under assets/, plus their provenance in ASSETS.md. Never add
  raw desktop/phone captures containing caller data or pairing secrets.
- Desktop mobile-call reception requires KFritz 0.5.0 or newer. Link the matching
  Linux release and Android APK together; do not claim KFritz is a relay needed
  for direct phone-to-TV delivery.
