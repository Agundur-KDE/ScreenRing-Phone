# Artwork and screenshot provenance

- `assets/kfritz-call-history.png` is an unchanged copy of the existing public
  [KFritz screenshot](https://github.com/Agundur-KDE/kfritz/blob/main/KFritz1.png).
  Git blob SHA-1: `05f750e66f191296733d754529443e23c92b1fdb`.
  It illustrates KFritz's call-history interface, not a new capture of a live
  phone call or the mobile-pairing settings. The image was visually checked
  before reuse; no new private device capture was taken.
- `assets/social-preview.jpg` is a new ScreenRing/KFritz promotional illustration,
  created with the built-in image generator from the existing project marks.
  It is not an application screenshot. The device drawing shows call alerts,
  not controls to answer or hang up calls. The final JPEG is 1280×640 and below 1 MB.
- KFritz is a separate [GPL-3.0-or-later project](https://github.com/Agundur-KDE/kfritz/blob/main/LICENSE).
  Linking to KFritz and showing its interface does not make this Android binary
  an open-source release. No Android application source is distributed here.
- The Android robot is derived from Google's Android artwork; credit to Google,
  under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
  See [Android brand guidelines](https://developer.android.com/distribute/marketing-tools/brand-guidelines).

To use the social image as the GitHub link preview, upload `social-preview.jpg`
under repository **Settings → General → Social preview → Edit → Upload an image**.
Embedding the image in the README alone does not set GitHub's social-preview field.
